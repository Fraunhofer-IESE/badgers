    Selectors: the observation-side contract for selecting deficit rows.

    A SELECTOR decides which rows of the input get a data quality deficit:

    Selector = Callable[[X, targets], dict[int, spec]]
    • keys = column positions (targets: the columns the mask applies to)
    • values = per-row boolean masks or float SCORES -- a (n,) array or, for Always-like constant levels, a scalar applied to the whole column
    • polarity: True/1.0 = R_X = 1 = deficit applied; False/0.0 = record as-is

    A spec is a scalar or (n,) array of values in [0, 1]: values restricted to {0, 1} are DECISIONS, anything else is a PROBABILITY (the chance the deficit is applied to that row). Two rng streams cooperate: the PRESET's own rng drives the spec draw (the decision or probability computation, the stochastic row draws, the row weights), while the CONSUMER's rng drives the realization -- every spec is realized with the single rule rng.random(n) < spec. selector=None means no selector draw at all (the consumer decides). Being in core, the package is modality-agnostic: time-series / graph / text generators can reuse the same contract with masks over their own axes.

    The presets are self-contained: their column scope (columns) and the column(s) they READ (bare int positions) are bound at construction, so an intensity sweep means constructing a new selector (nothing is swept on the call). There is deliberately no base class and no registry -- conformance to the :class:Selector protocol is defined by the call signature alone, and each preset's rule is inlined in __call__.

    Exact-count presets (CountSelector, ClassCountSelector) bind a requested ROW count at construction -- the machinery behind the outliers generators' count knobs.

    MODIFYING consumers preserve the input's shape and only ALTER the selected cells (missingness, noise, outliers, ...); SUBSAMPLING consumers (imbalance) DROP the selected rows, so their output is smaller than the input. The contract itself is only "which rows are selected, on which columns". All data used to determine selection, including class and driver columns, is supplied as X; there is no separate target argument.

    Layout: :mod:.base holds the contract (protocol, shared validation, consumer helpers); :mod:.value_free and :mod:.value_driven hold the presets, split along the one constructor-contract difference they have (value-free presets never read X, value-driven presets read column positions).

    class BernoulliSelector:
    """Selector: iid per-row, per-column deficit indicator draws.

    For each target column, whether a row is affected is an independent
    Bernoulli draw with probability ``rate``, independent of the data
    values. In the missingness literature this pattern is called
    "completely at random". One vectorized ``(n_rows, k)`` draw: column
    order follows ``targets`` order (RNG parity with the legacy
    per-variable draw order).

    Parameters
    ----------
    columns : int or sequence of int
        Column positions this selector covers.
    rate : float, in [0, 1]
        Per-cell selection probability.
    rng : numpy.random.Generator or None, default=None
        Random generator used for the draws.
    """

    def __init__(self, columns: int | Sequence[int], rate: float,
                 rng: np.random.Generator | None = None):
        self.columns = _validate_columns(columns)
        self.rate = _validate_rate(rate, "rate")
        self.rng = rng

    def __call__(self, X: np.ndarray, targets=None):
        _require_rng(self)
        targets = _resolve_targets(self, X, targets)
        draws = self.rng.random(size=(X.shape[0], len(targets))) < self.rate
        return {col: draws[:, i] for i, col in enumerate(targets)}

    def __repr__(self) -> str:
        return (f"BernoulliSelector(columns={self.columns!r}, "
                f"rate={self.rate!r})")

    class ClassCountSelector:
    """Selector: exactly ``counts[class_value]`` rows per listed class.

    The value-driven exact-count preset (the class-aware sibling of
    :class:`~badgers.core.selectors.value_free.CountSelector`). Reads the
    class labels from ``class_column`` ONCE; for every class value in
    ``counts`` exactly that many rows of the class are drawn WITHOUT
    REPLACEMENT (uniform) and the union mask is returned under every
    target. Classes absent from ``counts`` select nothing; a count for a
    class value missing from ``X`` raises (typo protection), and a count
    above the class size raises (an explicit count is a request, not a
    share -- unlike :class:`ClassSelector`'s share clipping).

    Parameters
    ----------
    columns : int or sequence of int
        Column positions this selector covers.
    class_column : int
        Position of the column holding the class labels.
    counts : dict mapping class_value -> int
        Exact number of rows selected per class value (ints >= 0).
    rng : numpy.random.Generator or None, default=None
        Random generator used for the row draws.
    """

    def __init__(self, columns: int | Sequence[int], class_column: int,
                 counts: dict, rng: np.random.Generator | None = None):
        self.columns = _validate_columns(columns)
        if not isinstance(class_column, (int, np.integer)):
            raise ValueError(
                f"class_column must be an int position, got {class_column!r}")
        self.class_column = int(class_column)
        for value, count in counts.items():
            if not isinstance(count, (int, np.integer)) or isinstance(count, bool):
                raise ValueError(
                    f"counts[{value!r}] must be an int, got {count!r}")
            if count < 0:
                raise ValueError(f"counts[{value!r}] must be >= 0, got {count}")
        self.counts = counts
        self.rng = rng

    def __call__(self, X: np.ndarray, targets=None):
        _require_rng(self)
        targets = _resolve_targets(self, X, targets)
        n_rows = X.shape[0]
        labels = X[:, self.class_column]
        values = set(np.unique(labels).tolist())
        unknown = [v for v in self.counts if v not in values]
        if unknown:
            raise ValueError(
                f"class value(s) {unknown!r} not found in column "
                f"{self.class_column} (found {sorted(values)!r})")
        mask = np.zeros(n_rows, dtype=bool)
        for class_value, count in self.counts.items():
            rows = np.flatnonzero(labels == class_value)
            if count > len(rows):
                raise ValueError(
                    f"counts[{class_value!r}]={count} exceeds the number "
                    f"of rows of class {class_value!r} ({len(rows)})")
            if count:
                # Sampling without replacement: sequential by nature.
                idx = self.rng.choice(rows, size=count, replace=False)
                mask[idx] = True
        return {t: mask for t in targets}

    def __repr__(self) -> str:
        return (f"ClassCountSelector(columns={self.columns!r}, "
                f"class_column={self.class_column!r}, "
                f"counts={self.counts!r})")

    class ClassSelector:
    """Selector: selects a fixed share of the rows of each listed class.

    Reads the class labels from ``class_column`` ONCE; for every class
    value in ``proportions`` exactly ``min(int(share * n_rows),
    n_rows_in_class)`` rows of that class are drawn WITHOUT REPLACEMENT
    (uniform). The class values are discovered from ``X``; a proportion
    for an absent class raises ``ValueError`` (typo protection). The
    resulting mask is returned under EVERY target column (one read,
    broadcast across targets).

    Parameters
    ----------
    columns : int or sequence of int
        Column positions this selector covers.
    class_column : int
        Position of the column holding the class labels.
    proportions : dict mapping class_value -> float in [0, 1]
        Share of the TOTAL row count selected per class value.
    rng : numpy.random.Generator or None, default=None
        Random generator used for the draws.
    """

    def __init__(self, columns: int | Sequence[int], class_column: int,
                 proportions: dict, rng: np.random.Generator | None = None):
        self.columns = _validate_columns(columns)
        if not isinstance(class_column, (int, np.integer)):
            raise ValueError(
                f"class_column must be an int position, got {class_column!r}")
        self.class_column = int(class_column)
        for value, share in proportions.items():
            _validate_rate(share, f"proportions[{value!r}]")
        self.proportions = proportions
        self.rng = rng

    def __call__(self, X: np.ndarray, targets=None):
        _require_rng(self)
        if not (0 <= self.class_column < X.shape[1]):
            raise ValueError(
                f"the selector's class_column {self.class_column} is not a "
                f"valid column position in X with {X.shape[1]} columns")
        targets = _resolve_targets(self, X, targets)
        n_rows = X.shape[0]
        col = X[:, self.class_column]
        values = set(np.unique(col).tolist())
        unknown = [v for v in self.proportions if v not in values]
        if unknown:
            raise ValueError(
                f"class value(s) {unknown!r} not found in column "
                f"{self.class_column} (found {sorted(values)!r})")
        mask = np.zeros(n_rows, dtype=bool)
        for class_value, share in self.proportions.items():
            rows = np.flatnonzero(col == class_value)
            # Share of the TOTAL row count, clipped to the class size.
            count = min(int(share * n_rows), len(rows))
            if count:
                # Sampling without replacement: sequential by nature.
                idx = self.rng.choice(rows, size=count, replace=False)
                mask[idx] = True
        return {col: mask for col in targets}

    def __repr__(self) -> str:
        return (f"ClassSelector(columns={self.columns!r}, "
                f"class_column={self.class_column!r}, "
                f"proportions={self.proportions!r})")

    class CountSelector:
    """Selector: exactly ``count`` distinct rows, one shared mask.

    The exact-count ROW preset: draws ``count`` row positions without
    replacement (uniform) and returns the same boolean mask under every
    target column — the requested count is exact at ROW level. This is
    the machinery behind the outliers generators' default count: an
    explicit count is a request, and a request that overflows the data
    raises.

    Parameters
    ----------
    columns : int or sequence of int
        Column positions this selector covers.
    count : int
        Number of rows to select; must be an int >= 0 and <= the number
        of rows of the ``X`` passed at call time.
    rng : numpy.random.Generator or None, default=None
        Random generator used for the row draws.
    """

    def __init__(self, columns: int | Sequence[int], count: int,
                 rng: np.random.Generator | None = None):
        self.columns = _validate_columns(columns)
        if not isinstance(count, (int, np.integer)) or isinstance(count, bool):
            raise ValueError(f"count must be an int, got {count!r}")
        if count < 0:
            raise ValueError(f"count must be >= 0, got {count}")
        self.count = int(count)
        self.rng = rng

    def __call__(self, X: np.ndarray, targets=None):
        _require_rng(self)
        targets = _resolve_targets(self, X, targets)
        n_rows = X.shape[0]
        if self.count > n_rows:
            raise ValueError(
                f"count {self.count} exceeds the number of rows of X "
                f"({n_rows}): an exact count cannot select more distinct "
                "rows than exist")
        if self.count == 0:
            empty = np.zeros(n_rows, dtype=bool)
            return {col: empty for col in targets}
        # Sampling without replacement: sequential by nature.
        idx = self.rng.choice(n_rows, size=self.count, replace=False)
        mask = _mask_from_indices(n_rows, idx)
        return {col: mask for col in targets}

    def __repr__(self) -> str:
        return (f"CountSelector(columns={self.columns!r}, "
                f"count={self.count!r})")

    class ExactCountSelector:
    """Selector: exactly ``int(rate * n_rows)`` rows per target column,
    drawn without replacement (uniform, or weighted by per-row
    probabilities).

    The exact-count sibling of :class:`BernoulliSelector`. Per column, a
    fixed number of affected rows, optionally with per-row selection
    probabilities ("soft" coupling).

    Parameters
    ----------
    columns : int or sequence of int
        Column positions this selector covers.
    rate : float, in [0, 1]
        Affected rows per column = ``int(rate * n_rows)`` (floor).
    weights : None, (n_rows, k) array, or callable ``(X) -> (n_rows, k)``
        Per-row selection probabilities, one column per target.
        ``None`` = uniform. The callable is evaluated per call (the
        caller binds any randomness inside it, BEFORE the row draws).
    rng : numpy.random.Generator or None, default=None
        Random generator used for the draws.
    """

    def __init__(self, columns: int | Sequence[int], rate: float,
                 weights: np.ndarray
                 | Callable[[np.ndarray], np.ndarray] | None = None,
                 rng: np.random.Generator | None = None):
        self.columns = _validate_columns(columns)
        self.rate = _validate_rate(rate, "rate")
        self.weights = weights
        self.rng = rng

    def _resolve_weights(self, X: np.ndarray, targets) -> np.ndarray | None:
        k = len(targets)
        if self.weights is None:
            return None
        w = self.weights(X) if callable(self.weights) else self.weights
        w = np.asarray(w, dtype=float)
        if w.shape != (X.shape[0], k):
            raise ValueError(
                f"weights must have shape ({X.shape[0]}, {k}), got {w.shape}")
        if (w < 0).any():
            raise ValueError("weights must be non-negative")
        return w

    def __call__(self, X: np.ndarray, targets=None):
        _require_rng(self)
        targets = _resolve_targets(self, X, targets)
        n_rows = X.shape[0]
        count = int(self.rate * n_rows)
        # Resolve the weights BEFORE the row draws: data-driven coupling
        # may consume rng draws itself, and those must precede the per-
        # column row draws (draw-order parity with the classic generators).
        weights = self._resolve_weights(X, targets)
        masks = {}
        for i, col in enumerate(targets):
            # Sampling without replacement: sequential by nature.
            p = None if weights is None else weights[:, i]
            if count == n_rows and p is not None:
                # The whole population is requested: the draw is forced
                # regardless of the weights (numpy rejects rows whose
                # weight is exactly 0 in that case) -- bypass the sampler.
                idx = np.arange(n_rows)
            else:
                idx = self.rng.choice(n_rows, size=count, replace=False, p=p)
            masks[col] = _mask_from_indices(n_rows, idx)
        return masks

    def __repr__(self) -> str:
        return (f"ExactCountSelector(columns={self.columns!r}, "
                f"rate={self.rate!r})")

    class ProportionalSelector:
    """Selector: the deficit probability is proportional to a column's value.

    Value-driven, FRACTIONAL rule: the per-row score is the min-max
    normalized value of ``column`` rescaled to sum to 1 (a constant
    column yields the uniform score). Deterministic (no rng); the
    consumer decides how the probabilities are realized.

    Parameters
    ----------
    columns : int or sequence of int
        Column positions this selector covers.
    column : int
        Position of the column whose values drive the scores.
    """

    def __init__(self, columns: int | Sequence[int], column: int):
        self.columns = _validate_columns(columns)
        if not isinstance(column, (int, np.integer)):
            raise ValueError(f"column must be an int position, got {column!r}")
        self.column = int(column)

    def __call__(self, X: np.ndarray, targets=None):
        targets = _resolve_targets(self, X, targets)
        col = X[:, self.column].astype(float)
        span = col.max() - col.min()
        unit = (col - col.min()) / span if span > 0 else np.ones_like(col)
        scores = normalize_proba(unit)
        return {c: scores for c in targets}

    def __repr__(self) -> str:
        return (f"ProportionalSelector(columns={self.columns!r}, "
                f"column={self.column!r})")

    class TopQuantileSelector:
    """Selector: selects rows where the column value is >= its quantile.

    Deterministic rule: threshold = ``np.quantile(X[:, driver], quantile)``
    (``driver=None``: the column's own threshold). A row is selected when the
    driver value is ``>= threshold``; the same mask is returned under
    every target.

    Parameters
    ----------
    columns : int or sequence of int
        Column positions this selector covers.
    column : int
        Required read column; unused when ``driver`` is set. In self
        mode (``driver=None``) the threshold is compared against this
        column (``column == driver``).
    quantile : float, in [0, 1]
        The quantile forming the threshold (``>=`` comparison).
    driver : int or None, default=None
        Driver column position whose values form the threshold and mask.
        ``None`` = self mode (driver is ``column``).
    """

    def __init__(self, columns: int | Sequence[int], column: int,
                 quantile: float, driver: int | None = None):
        self.columns = _validate_columns(columns)
        if not isinstance(column, (int, np.integer)):
            raise ValueError(f"column must be an int position, got {column!r}")
        self.column = int(column)
        self.driver = self.column if driver is None else int(driver)
        self.quantile = _validate_rate(quantile, "quantile")

    def __call__(self, X: np.ndarray, targets=None):
        targets = _resolve_targets(self, X, targets)
        dcol = X[:, self.driver]
        threshold = np.quantile(dcol, self.quantile)
        mask = dcol >= threshold
        return {col: mask for col in targets}

    def __repr__(self) -> str:
        return (f"TopQuantileSelector(columns={self.columns!r}, "
                f"column={self.column!r}, quantile={self.quantile!r}, "
                f"driver={self.driver!r})")

    def get_selected_fields(X, selector, rng):
    """Realized selection field: bool array ``(n_rows, len(targets))``.

    Column *i* corresponds to the selector's *i*-th target (its own
    ``columns`` when it declares a scope, else every column). Narrow on
    purpose: the caller decides how to write the field back into full
    coordinates.

    ``selector=None`` returns every column all-True WITHOUT consuming rng
    draws — the backward-compatible default of consuming generators.

    Single realization rule (shared with every consumer):
    ``rng.random(n) < spec``; the mask is decided against the UN-mutated
    input. Constant decisions (a scalar spec of exactly ``0.0`` or
    ``1.0``) are deterministic and realized WITHOUT consuming rng draws,
    so default selectors built on ``AlwaysSelector`` cost no draws.
    """
    n_rows, n_cols = X.shape
    if selector is None:
        return np.ones((n_rows, n_cols), dtype=bool)
    targets = _resolve_targets(selector, X, None)
    out = selector(X, targets=list(targets))
    unknown = [c for c in out if c not in targets]
    if unknown:
        raise ValueError(
            f"selector returned keys {unknown} not in targets {targets}")
    field = np.zeros((n_rows, len(targets)), dtype=bool)
    for i, col in enumerate(targets):
        if col in out:
            spec = out[col]
            _check_spec(spec, n_rows)
            spec = np.asarray(spec)
            if spec.ndim == 0 and float(spec) in (0.0, 1.0):
                # constant decision: deterministic, no rng draw consumed
                field[:, i] = float(spec)
            else:
                field[:, i] = rng.random(n_rows) < np.broadcast_to(spec, (n_rows,))
    return field

    def resolve_class_column(selector, X: np.ndarray):
    """Recover the class column position from a value-reading selector.

    Value-driven presets expose a ``class_column`` (or ``column``)
    attribute holding the read column position. Returns ``None`` when the
    selector has no such attribute or the value is out of range.
    """
    col = getattr(selector, "class_column", None)
    if col is None:
        col = getattr(selector, "column", None)
    if col is not None and 0 <= col < X.shape[1]:
        return col
    return None
